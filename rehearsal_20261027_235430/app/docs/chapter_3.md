# 3. ПРОГРАММНАЯ РЕАЛИЗАЦИЯ И ТЕСТИРОВАНИЕ СИСТЕМЫ

## 3.1 Выбор стека технологий и архитектура программного комплекса

При проектировании веб-платформы автоматизации процессов распределения и согласования тем дипломных и курсовых работ кафедры ВТиПО ключевыми критериями являлись:
- **Высокая доступность и скорость отклика:** Минимизация задержек при одновременной работе потока студентов.
- **Отказоустойчивость и безопасность:** Разделение уровней доступа, хеширование паролей криптографическими функциями SHA-256 с солью, ведение журнала аудита всех решений комиссии.
- **Интерактивность без перегрузки страниц:** Использование протокола WebSocket для мгновенной доставки уведомлений об изменении статуса заявки.

В качестве основного серверного фреймворка выбран **FastAPI (Python 3.11)**, обладающий нативной поддержкой асинхронных корутин (`async/await`), статической валидацией типов через **Pydantic v2** и автоматической генерацией документации спецификации OpenAPI.

В качестве реляционной СУБД на этапе прототипирования и внедрения используется **SQLite 3**, доступ к которой организован через ORM-библиотеку **SQLAlchemy 2.0**. Модель данных поддерживает каскадные обновления и внешние ключи для сущностей пользователей, тем, заявок, контрольных точек и логов аудита.

Клиентская часть реализована по архитектуре Single Page Application (SPA) на чистом **Vanilla JavaScript**, утилитарном CSS-фреймворке **Tailwind CSS** и библиотеке визуализации **Chart.js** для аналитических панелей заведующего кафедрой.

## 3.2 Реализация ключевых модулей системы

### 3.2.1 Алгоритм стабильного паросочетания Гейла–Шепли
Для устранения конфликтов интересов и субъективизма при распределении популярных тем реализован алгоритм Гейла–Шепли (модификация задачи о назначениях с квотами):
1. Каждый студент ранжирует до 3 интересующих его тем по приоритету (Top-3).
2. Руководитель/кафедра ранжирует претендентов на основе их академического рейтинга (GPA) и профильных навыков.
3. Алгоритм итеративно сопоставляет заявки: студент предлагает свою кандидатуру теме с наивысшим приоритетом. Если квота темы заполнена, претендент с более высоким баллом вытесняет студента с наименьшим GPA, который переходит к следующему шагу своего списка предпочтений.
4. Процесс сходится за конечное число шагов, формируя слабо доминирующее стабильное паросочетание без блокирующих пар.

### 3.2.2 Автоматический перевод на запасную тему (Fallback)
В случае отклонения заявки научным руководителем (например, по причине несоответствия компетенций студента) система обращается к таблице `Preference`, находит следующий приоритетный вариант студента со свободной квотой, автоматически формирует заявку в статусе `SUBMITTED` и транслирует персональное уведомление через WebSocket-соединение.

### 3.2.3 Модуль проверки уникальности тем (Антидубликат)
На основе метрики сходства последовательностей `SequenceMatcher` вычисляется коэффициент подобия формулировки новой темы со всеми зарегистрированными темами текущего и предшествующих учебных лет. При совпадении $\ge 75\%$ система блокирует подачу дубликата и выдает рекомендацию по корректировке предметной области.

### 3.2.4 Интеллектуальный ассистент формулировок тем
Модуль выполняет нормализацию неформальных пользовательских запросов и на основе онтологических правил кафедры синтезирует академические наименования тем в соответствии с ГОСТ 7.32, а также генерирует первичный календарный план и состав инженерных задач дипломного проекта.

## 3.3 Программа и методика испытаний

Тестирование серверных компонентов выполнено с применением фреймворка `pytest` и HTTP-клиента `httpx`. Проведены следующие виды испытаний:
1. **Интеграционные тесты API:** Проверка цикла регистрации, аутентификации, генерации токенов сессий и обработки некорректных учетных данных (код ответа 401).
2. **Алгоритмические тесты антидубликата:** Проверка чувствительности алгоритма на наборе схожих и уникальных текстовых формулировок.
3. **Нагрузочное тестирование WebSocket:** Проверка устойчивости пула активных подключений при массовой рассылке сообщений о статусе утверждения приказов.

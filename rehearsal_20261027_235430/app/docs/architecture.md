## 3. Математическое описание алгоритма Гейла–Шепли

### Постановка задачи
Имеется множество студентов $S = \{s_1, s_2, \dots, s_n\}$ и множество тем $T = \{t_1, t_2, \dots, t_m\}$.
Каждая тема $t_j$ имеет квоту мест $q_j \in \mathbb{N}$.

- Каждый студент $s_i$ задает строгое линейное отношение предпочтения $\succ_{s_i}$ на подмножестве тем $T_i \subseteq T$ (до 3 тем (Top-3)).
- Каждая тема $t_j$ ранжирует студентов $\succ_{t_j}$ по академическому рейтингу (GPA): $s_a \succ_{t_j} s_b \iff \text{GPA}(s_a) > \text{GPA}(s_b)$.

### Шаги выполнения
1. **Инициализация:** Все студенты свободны. Множество зачисленных на тему $t_j$: $M(t_j) = \emptyset$.
2. **Итерация:** Пока существует свободный студент $s_i$, у которого остались нерассмотренные предпочтения:
   - Студент делает предложение наиболее предпочтительной для него теме $t_j$.
   - Если $|M(t_j)| < q_j$: студент $s_i$ предварительно зачисляется: $M(t_j) \leftarrow M(t_j) \cup \{s_i\}$.
   - Если $|M(t_j)| = q_j$: находится студент с наименьшим GPA: $s_{\min} = \arg\min_{s \in M(t_j)} \text{GPA}(s)$.
     - Если $\text{GPA}(s_i) > \text{GPA}(s_{\min})$: $s_{\min}$ исключается и возвращается в список свободных, а $s_i$ зачисляется:
       $M(t_j) \leftarrow (M(t_j) \setminus \{s_{\min}\}) \cup \{s_i\}$.
     - Иначе: студент $s_i$ отклоняется и остается свободным для следующего предложения.
3. **Завершение:** Алгоритм завершается при отсутствии предложений. Доказано, что итоговое паросочетание является **слабо устойчивым** и не содержит блокирующих пар $(s, t)$.

# META — Цифровая платформа управления ВКР и дипломным проектированием

Автоматизированная платформа распределения и мониторинга подготовки выпускных квалификационных работ (ВКР) кафедры ВТиПО.

---

## 🛠 Технологический стек

- **Backend**: Python 3.11, [FastAPI](https://fastapi.tiangolo.com/), [SQLAlchemy 2.0](https://www.sqlalchemy.org/)
- **Frontend**: Single Page Application (SPA) на чистом **Vanilla JavaScript**, [Tailwind CSS CDN](https://tailwindcss.com/), Chart.js
- **База данных**: SQLite 3 (с обязательной поддержкой `PRAGMA foreign_keys = ON`, каскадными связями и проверками целостности)
- **Безопасность**: 
  - Аутентификация на основе серверных сессий и Bearer токенов
  - Хеширование паролей: **PBKDF2 HMAC SHA-256** (100 000 итераций, уникальная криптографическая соль)
  - Ролевой доступ (RBAC): `student`, `teacher`, `head`, `admin`
  - Защита от Stored и DOM XSS (экранирование `escapeHtml` / `textContent`)
  - Защищенная загрузка файлов: ограничение размера, проверка расширений, защита от Path Traversal, генерация безопасных имен
- **Алгоритмы**:
  - Распределение тем: модифицированный алгоритм **Гейла–Шепли** с квотами на основе приоритетов студентов (**Top-3**) и рейтинга GPA
  - Проверка уникальности тем: n-граммный анализ и вычисление схожести строк (SequenceMatcher)
  - Нормоконтроль ГОСТ (.docx): анализ полей, гарнитуры Times New Roman (с учетом наследования стилей), кегля 14 пт, полуторного интервала и структуры
- **Документооборот**:
  - Генерация официального приказа об утверждении тем (DOCX и двухколоночный PDF)
  - Уникальный проверочный код приказа (`ORDER-2026-XXXX`) и QR-код со ссылкой на публичную страницу верификации `/verify/{code}`
  - Честная верификация: контрольная сумма **SHA-256** от байтов PDF-файла и запись в реестре META

## 🚀 Быстрый старт

### Локальный запуск

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Запуск сервера FastAPI
uvicorn main:app --reload --port 8000
```

Сервер доступен по адресу: **http://localhost:8000**

### Запуск через Docker Compose

```bash
docker compose up -d
```

Платформа доступна по адресу: **http://localhost** (через Nginx reverse proxy).
